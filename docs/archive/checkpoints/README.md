# Historical checkpoint archive

These records preserve checkpoint decisions, stop approvals, migration history and verification evidence. Their claims refer to their original checkpoint dates. They are not the primary current setup or architecture documentation.

- [D15 freeze audit](d15/D15-REPORT.md), [findings](d15/D15-FINDINGS.md) and [authorization matrix](d15/D15-AUTHORIZATION-MATRIX.md) are grouped together.
- Earlier available D4A–D14 reports and analysis records retain their original filenames in this directory. Missing checkpoint files have not been invented.
- [Foundation README](FOUNDATION-README.md) preserves the original root README, including historical D3 details and setup statements superseded by later checkpoints.

Historical source links and local-machine paths may remain as factual evidence. Repository-document navigation links are repaired for the archive layout.

For current guidance use the [documentation index](../../README.md) and [HR V1 freeze summary](../../modules/hr/HR-V1-FREEZE.md). The authoritative accepted code reference is Git tag `hr-backend-v1`.
