## Reusable contract

- `DetailFacts` renders semantic `dl`/`dt`/`dd` groups. Labels use the existing 600 weight; values use the new explicit 400 body-weight token. Both use readable body typography, 4px label/value spacing and token-based group spacing. Missing null facts explicitly display muted “Not recorded”; zero remains zero.
- `.ui-detail-list` applies the same hierarchy to existing definition lists without forcing their layout into a grid. Form labels and table headers are untouched.
- Default detail grids use two columns, three at desktop, one on mobile; inspection drawers cap at two columns and stack on mobile. Long identifiers wrap without widening the page.
- `LinkButton` reuses the existing button variant builder and real React Router links, retaining normal link semantics, routing, keyboard operation and browser behavior. It adds no request or command handling.
- `BackLink` composes the shared outline link with decorative ArrowLeft and explicit destination text.
- `.ui-record-actions` centralizes wrapping/alignment/gaps. Existing compact 36px desktop and 44px mobile controls, focus rings, interaction timing and reduced-motion behavior remain authoritative.
- The shared destructive-outline variant identifies consequential end-employment navigation without executing the action. Existing confirmations still govern submission.
- Obsolete employee detail/action CSS and the redundant attendance detail rule were removed; no broad stylesheet rewrite or new dependency.
