## Sections and definitions

- Workforce overview: server Employee totalCount, explicitly including inactive directory records; no inferred active workforce count or employment-status analytics.
- Today's attendance: server-defined business date/timezone, effective employees, scheduled, not scheduled, late and approved-leave counts. Categories overlap; no inferred current presence, deduction or combined percentage.
- Pending leave: server Pending total, at most five recent requests, employee identity/type/date/status only. Reasons and evidence are not exposed. Static queue rows are not presented as actionable records.
- Attendance attention: today's separate RequiresReview, ReadyToFinalize, Stale and ConfigurationRequired counts. Reuses the same attendance query; configuration is displayed once. No summed backlog. Staleness is a source change, not an HR violation.
- Permitted HR destinations: existing placeholders and real User Accounts navigation. No approval, finalization, employee CRUD, Payroll, Leave or document workflow added. Attendance navigation requires Attendance.Read; Reporting.Read alone does not confer the operational route.
